# Reference Links

Consult these sources when the task needs their subject matter; this list is not required preflight reading.

- [Conventional Commits 1.0.0](https://www.conventionalcommits.org/en/v1.0.0/) — commit subject semantics and breaking-change notation.
- [Google developer documentation style guide](https://developers.google.com/style) — technical language and documentation patterns.
- [Microsoft Writing Style Guide](https://learn.microsoft.com/en-us/style-guide/welcome/) — technical terminology and interface instructions.
- [Apple Style Guide](https://support.apple.com/guide/applestyleguide/welcome/web) — Apple-specific names and interfaces.
- [TypeScript](https://www.typescriptlang.org/) — compiler behavior, configuration, and version-specific migration evidence.
- [Oxc](https://oxc.rs/) — formatter and linter configuration.
- [std-kit](https://github.com/luastoned/std-kit) — utility APIs for projects that use or intentionally adopt this shared preference.
- [DESIGN.md specification](https://github.com/google-labs-code/design.md/blob/main/docs/spec.md) — design-token format and compatibility.

Its model-specific observations are context for evaluating guidance, not universal requirements or a reason to discard useful constraints for other runtimes.
